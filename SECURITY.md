# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability** (GitHub private vulnerability reporting).
3. Describe the problem, how to reproduce it, and what an attacker could do with it.

The report is visible only to the maintainers. You'll get a reply in the advisory thread, and a fix will be published with a security advisory once it's ready.

## Scope

This covers the code in this repository: the app server, the web client, the transcriber service and the deploy scripts. Problems in LiveKit, Railway or other dependencies should go to those projects, though a heads-up here is welcome if this project is affected.
